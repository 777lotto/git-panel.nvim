==============================================================================
1. REQUIREMENTS                                           *git-panel-requirements*

Neovim 0.10 or newer and the Git executable on $PATH. The plugin has no Lua
dependencies. GitHub CLI (gh) is optional; when installed and authenticated it
can create a GitHub repository during the first push.

==============================================================================
2. INSTALLATION                                             *git-panel-installation*

With lazy.nvim: >lua

    {
      "777lotto/git-panel.nvim",
      cmd = { "GitPanel", "GitPanelSplit" },
    }
<
The default bet branch is production. Release tags provide immutable versions;
the persistent bluff branch contains integration work.

==============================================================================
3. COMMANDS                                                     *git-panel-commands*

:GitPanel             Open the dashboard in a tab page.
:GitPanelSplit        Open the dashboard as a left split.

==============================================================================
4. KEYS                                                             *git-panel-keys*

The following mappings are local to the panel buffer:

<Tab>       Toggle Staged/Unstaged and Committed/Uncommitted views.
<CR>        Act on the current section, branch, worktree, file, commit, or push.
<NL>/<kEnter>  The LF and keypad forms of Enter perform the same action.
za          Fold or unfold the current section.
s / u       Stage or unstage the current file.
S / U       Stage all or unstage all.
x           Discard the current file's changes after confirmation.
o / t       Resolve a conflict by taking ours or theirs, then stage it.
> / A       Continue or abort an in-progress Git operation.
c / C       Commit staged changes or stage everything and commit.
a           Amend the last commit.
b / R / d   Create, rename, or delete a branch.
m           Merge the branch under the cursor into the current branch.
W           Create a worktree.
F / P / f   Pull with --ff-only, push/publish, or fetch all remotes and prune.
            With no remote, P can create a GitHub repo using gh or attach an
            existing remote URL as origin, then push with upstream tracking.
L           Toggle full-tab and left-split layouts.
r           Refresh.
? / g?      Open the in-panel help window.
q           Close the panel.

==============================================================================
5. LUA API                                                           *git-panel-api*

The module is returned by: >lua

    local git_panel = require("git_panel")
    git_panel.open("tab")    -- or "split"
    git_panel.refresh()
    git_panel.close()
<

==============================================================================
6. BRANCHES AND SUPPORT                                      *git-panel-development*

Linux is tested on Neovim 0.10, 0.11, and 0.12. macOS is smoke-tested on the
current stable Neovim. Platform behavior is not separated into OS branches or
GitHub Environments.

Development branches start from and merge into bluff. Tested changes are
promoted from bluff into the production/default bet branch.
